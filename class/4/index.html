04

/effects 영상 이펙트 넣기

영상 하나 + /effects 이름 한 줄 → 모션그래픽 편집까지 Claude Code가 해 주는 스킬이에요. 편집 프로그램 없이 되고, 내 PC에서 돌아서 크레딧이 들지 않아요.

무엇을 배우나

  • 세로 영상을 Claude Code 채팅창에 끌어다 놓고 /effects orbit처럼 이펙트 이름을 치면, 머리 주위로 카드가 돌거나 글자가 머리 뒤로 들어가는 편집 영상이 나와요.
  • AI가 영상을 새로 만드는 게 아니에요. 내 영상 위에 모션그래픽을 얹는 편집 도구예요. 얼굴을 찾고(OpenCV YuNet), 사람만 오려 내서(MediaPipe) 그래픽을 머리 뒤·옆에 넣은 다음 ffmpeg로 렌더해요.
  • 결과는 원본 옆에 원본이름_effects.mp4로 생겨요. 소리는 원본 그대로, 기본 1080p예요(4K도 되지만 느려요).
  • 4강 순서: 설치 → 이펙트 하나 넣기 → 타이밍 지정·여러 개 쌓기 → 내 색·내 글자로 바꾸기

설치 명령어 (복사해서 붙여넣기)

터미널은 따로 설치 안 해도 돼요.

  • Windows: 시작 → PowerShell 검색 → 열기
  • Mac: ⌘+Space → 터미널 검색 → 열기

아래 칸의 복사 버튼을 눌러 붙여넣고 Enter. 한 칸씩 차례대로 해요. 3강 때 Claude Code·Python을 이미 깔았으면 ③ ffmpeg부터 하면 돼요.

② Python 설치 — python.org/downloads에서 설치 파일을 받아 설치해요. 끝나면 터미널을 닫고 다시 열어요.

④ Git — 터미널에 git을 치면 설치 창이 떠요. 이미 있으면 버전 안내가 나와요.

설치 — 스킬 넣기

스킬 폴더 위치

  • Windows: C:\Users\(내이름)\.claude\skills\effects\
  • Mac: /Users/(내이름)/.claude/skills/effects/
  • effects 폴더 안에 SKILL.md가 바로 보여야 해요(폴더가 한 겹 더 생기면 안 돼요). .claude 폴더가 안 보이면 "숨김 파일 보기"를 켜세요.

방법 A. Claude Code에 부탁하기 (가장 쉬움)

Claude Code를 열고 아래 문장을 그대로 붙여넣어요.

Mac

Claude Code에 붙여넣기
github.com/Vibha-Ramprakash/claude-video-effects 스킬을 ~/.claude/skills/effects 에 설치해줘. 설치하고 scripts/setup.sh 를 돌려서 READY 가 나오는지 확인해줘.

Windows — 동봉된 setup.sh가 Mac 경로(.venv/bin/python)를 써서 Windows에서는 한 번 막혀요. 그래서 한 줄을 더 붙여요.

Claude Code에 붙여넣기
github.com/Vibha-Ramprakash/claude-video-effects 스킬을 ~/.claude/skills/effects 에 설치해줘.
윈도우라서 setup.sh 대신 스킬 폴더에서 python -m venv .venv 를 만들고 .venv\Scripts\python.exe -m pip install -r requirements.txt 로 설치해줘.

방법 B. 직접 명령어

Windows (PowerShell) — 한 줄씩 붙여넣고 Enter. 마지막 줄은 몇 분 걸려요.

PowerShell
git clone https://github.com/Vibha-Ramprakash/claude-video-effects "$HOME\.claude\skills\effects"
cd "$HOME\.claude\skills\effects"
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

다 되면 아래 줄을 쳐서 READY가 나오면 성공이에요.

PowerShell
.venv\Scripts\python.exe -c "import mediapipe, cv2, PIL, numpy; print('READY')"

Mac (터미널)

터미널
git clone https://github.com/Vibha-Ramprakash/claude-video-effects ~/.claude/skills/effects
bash ~/.claude/skills/effects/scripts/setup.sh

READY가 나오면 성공이에요. NEED_FFMPEG가 나오면 ffmpeg를, NEED_PYTHON이 나오면 Python 3.10 이상을 먼저 깔고 다시 돌려요.

설치 후 Claude Code 껐다 켜기

설치가 끝나면 Claude Code를 완전히 껐다 다시 켜요. 그래야 새 스킬을 읽어요. 다시 켠 뒤 /effects를 쳤을 때 목록에 뜨면 성공이에요.

사용법

  1. 1

    Claude Code를 열어요.

  2. 2

    영상 파일을 채팅창에 끌어다 놓아요. 세로 영상이고 머리 위에 여백이 있어야 잘 돼요.

  3. 3

    /effects 이름을 쳐요. 타이밍은 말로 붙여도 돼요.

Claude Code에 입력
/effects orbit
/effects orbit 3초부터 6초까지
/effects spotlight "불 꺼" 할 때, 뒤에 CLAUDE 글자
/effects glass-widgets 처음 3초
/effects comment-box 마지막에, CLAUDE 입력
  • 처음 한 번은 Claude가 스스로 준비해요(1–3분).
  • 타이밍을 말로: "'봐봐'라고 할 때"라고 하면 Claude가 음성을 받아 적어서 정확한 초를 찾아요. 처음 쓸 때 받아쓰기 도구(faster-whisper)를 1분쯤 설치해요.
  • 이펙트 하나는 1.5–4초로 짧게 넣는 게 제일 보기 좋아요.
  • 여러 개 쌓기: "6–10초 locked-on, 10–13초 orbit, '노'라고 할 때 reject-stamp 넣어줘"
  • Claude가 렌더 전에 확인용 사진을 몇 장 뽑아서 글자가 얼굴을 가리는지 보고 고친 다음 렌더해요.
  • 결과는 원본 옆 원본이름_effects.mp4. Claude는 초안을 만들어 주는 거고, 올리기 전 확인은 내가 해요.
  • 처음에 영어로 랜더링이 되는데, 이 부분을 한국어로 수정해 달라고 1차 가공을 한번 더 하시면 돼요.

알아둘 한계

  • 스타터 버전이에요. 원작자도 "내 릴스 편집과 똑같지 않다(효과음·타이밍을 손으로 다듬었다)"고 적어 뒀어요. 원작자의 유료 버전(Hop Studio)에는 이펙트가 220개 이상 있다고 README에 나와 있어요.
  • 효과음·자막은 안 넣어 줘요. CapCut 같은 편집 앱에서 넣으면 돼요.
  • 이펙트 안 한글 글자는 깨져요. 들어 있는 폰트가 영문 전용이라 한글이 네모로 나와요(직접 확인했어요). text=, name= 같은 글자는 영어로 쓰세요.
  • glass-widgets 기본값에 원작자 이름(Vibha)·핸들(@vibha.in.progress)과 샘플 숫자가 들어 있어요. name=, handle=로 내 이름·계정을, text=로 내 숫자를 넣어요(영어로). 예: /effects glass-widgets name=YourName handle=@your.handle text=12K
    pastel-word·check-pills·profile-wall·comment-box도 기본값에 원작자 이름·핸들이 들어가 있으니 "이름은 OO, 핸들은 @OO로 바꿔줘"라고 말해요.
  • Windows에서는 첫 설정이 한 번 막혀요. 동봉된 setup.sh가 Mac 경로를 써서예요. 위 Windows 설치 방법대로 하면 돼요.
  • 얼굴을 따라가는 방식이라 얼굴이 잘 보이는 세로 영상이 제일 잘 돼요. 얼굴이 화면 가운데를 넘나들면 todo 카드가 좌우로 튈 수 있어요.
  • 렌더 시간: 저희 테스트 PC(Windows)에서 8초짜리 영상에 이펙트 하나를 넣는 데 30–50초쯤 걸렸어요. PC 사양에 따라 달라요.

자주 막히는 것

  • 설치했는데 /effects가 안 보여요 → Claude Code를 완전히 껐다 켜요. 그래도 없으면 폴더가 한 겹 더 들어갔는지 확인해요(skills\effects\claude-video-effects\SKILL.md처럼 되면 안 되고, skills\effects\SKILL.md여야 해요).
  • Windows에서 setup.sh 오류 / .venv/bin/python이 없다고 나와요 → Claude에게 "윈도우라서 .venv\Scripts\python.exe 를 써줘"라고 하거나, 위 방법 B의 Windows 명령을 직접 실행해요.
  • NEED_FFMPEG / NEED_PYTHON → ffmpeg 또는 Python 3.10 이상을 깔고, 터미널(PowerShell)을 닫았다 다시 열어요.
  • 영상이 한글 이름 폴더에 있어요 → Windows에서는 확인용 사진 저장이 실패할 수 있어요. 영상을 영문 이름 폴더(예: C:\videos\clip.mp4)로 옮기고 다시 해요.
  • 한글 때문에 인코딩 오류가 나요(Windows) → Claude에게 "PYTHONUTF8=1 켜고 다시 해줘"라고 해요.
  • unrecognized arguments 오류 → Claude에게 "fx.py는 이펙트 이름, 입력 파일, 출력 파일을 먼저 쓰고 옵션은 뒤에 써줘"라고 해요.
  • 글자가 네모로 나와요 → 한글이라서예요. 영어로 바꿔 달라고 해요.
  • 글자가 얼굴을 가려요 → 보이는 대로 말하면 위치를 옮기고 다시 렌더해요.
