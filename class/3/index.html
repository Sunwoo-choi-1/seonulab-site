03

상세페이지 만들기

기획안 → 상세페이지 → 스마트스토어·쿠팡에 바로 올릴 이미지까지 AI가 만들어 주는 스킬이에요. 포토샵·디자이너·코딩 지식 없이 돼요.

파일 받기

sangsepage-skill-set.zip

압축 안에는 폴더 두 개와 안내 파일 하나가 들어 있어요.

  • selling-product-page — 상세페이지 스킬 (템플릿 4종: 연출형·정보설득형·매거진형·실사형 / 카테고리 15개)
  • impeccable — 디자인 마감 스킬 (같이 넣어 두면 디자인이 한 단계 좋아져요)
  • INSTALL.txt — 이 페이지와 같은 설치 안내

깃허브: github.com/Sunwoo-choi-1/selling-product-page-skill (공개 저장소 — 누구나 받을 수 있어요)

준비물

구분필요한 것메모
필수Claude Code (Pro 이상) 또는 Codex (ChatGPT 유료)터미널에서 쓰는 프로그램 (웹·채팅창 아님)
필수Python 3.10 이상업로드용 JPG 뽑기
필수playwright·pillow파이썬 패키지 (JPG 찍기·자르기)
AI 이미지 (선택)힉스필드(Higgsfield) 유료 구독 또는 GPT 이미지(ChatGPT)둘 다 없으면 내 사진만으로도 돼요

설치 명령어 (복사해서 붙여넣기)

터미널은 따로 설치 안 해도 돼요.

  • Windows: 시작 → PowerShell 검색 → 열기
  • Mac: ⌘+Space → 터미널 검색 → 열기

아래 칸의 복사 버튼을 눌러 붙여넣고 Enter. 한 칸씩 차례대로 해요.

Windows (PowerShell)

① Claude Code 설치
irm https://claude.ai/install.ps1 | iex
① 또는 Codex 설치
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
② Python 설치 — 끝나면 PowerShell을 닫고 다시 열어요
winget install -e --id Python.Python.3.12 --override "/quiet PrependPath=1"
③ playwright·pillow 설치
python -m pip install playwright pillow

Mac (터미널)

① Claude Code 설치
curl -fsSL https://claude.ai/install.sh | bash
① 또는 Codex 설치
curl -fsSL https://chatgpt.com/codex/install.sh | sh

② Python 설치 — python.org/downloads에서 설치 파일을 받아 설치해요(brew로 깔면 다음 단계가 막힐 수 있어요). 끝나면 터미널을 닫고 다시 열어요.

③ playwright·pillow 설치
python3 -m pip install playwright pillow
④ Mac에 Chrome이 없으면 이것도 한 번 (Windows는 Edge가 있어서 필요 없어요)
python3 -m playwright install chromium

잘 깔렸는지 확인

버전 숫자가 나오면 성공이에요. Codex를 깔았으면 claude 대신 codex --version, Mac은 python 대신 python3.

shell
claude --version
shell
python --version
막히면 Claude Code(또는 Codex)를 열고 "파이썬이랑 playwright 설치됐는지 확인하고 없으면 설치해줘"라고 하면 대신 해 줘요.

설치 — Claude Code

스킬 폴더 위치

  • Windows: C:\Users\(내이름)\.claude\skills\
  • Mac: /Users/(내이름)/.claude/skills/
  • .claude 폴더가 안 보이면 "숨김 파일 보기"를 켜세요. skills 폴더가 없으면 새로 만들면 돼요.

방법 A. zip 파일

  1. 위 sangsepage-skill-set.zip을 받아 압축을 풉니다.
  2. selling-product-page 폴더와 impeccable 폴더를 통째로 스킬 폴더에 넣습니다.
    → skills\selling-product-page\SKILL.md가 바로 보여야 해요(폴더가 한 겹 더 생기면 안 돼요).
  3. Claude Code를 껐다 켭니다.

방법 B. 깃허브

제일 쉬운 건 Claude Code(또는 Codex)에 저장소 주소를 주고 "이 저장소의 두 폴더를 내 스킬 폴더에 설치해줘"라고 하는 거예요. Git이 없으면 알아서 깔고 설치해 줘요.

직접 명령어를 칠 때 Git이 없다면:

  • Mac: git을 치면 설치 창이 떠요 → 설치 후 아래 명령을 다시 실행
  • Windows: 아래 한 줄을 먼저 실행하고 PowerShell을 다시 열어요
PowerShell
winget install -e --id Git.Git
Windows (PowerShell)
git clone https://github.com/Sunwoo-choi-1/selling-product-page-skill.git $HOME\sangsepage
Copy-Item -Recurse -Force $HOME\sangsepage\selling-product-page, $HOME\sangsepage\impeccable $HOME\.claude\skills\
Mac (터미널)
git clone https://github.com/Sunwoo-choi-1/selling-product-page-skill.git ~/sangsepage
mkdir -p ~/.claude/skills && cp -R ~/sangsepage/selling-product-page ~/sangsepage/impeccable ~/.claude/skills/

설치 확인

Claude Code에서 /selling-product-page를 쳤을 때 목록에 뜨면 성공이에요.

AI 이미지 — 힉스필드 또는 GPT 이미지

  • 힉스필드(Higgsfield) — 연결해 두면 스킬이 장면·연출 컷을 직접 만들어요. 유료 구독이 필요해요.
  • GPT 이미지(ChatGPT) — 힉스필드가 없으면 스킬이 섹션별 이미지 프롬프트를 써 줘요. ChatGPT에 붙여넣어 만들고, 받은 이미지를 작업 폴더 images 안에 넣으면 돼요.

힉스필드 MCP 연결

API 키 없이 힉스필드 계정 로그인으로 연결돼요. 연결 방법(claude.ai 커넥터·Claude Code·CLI·Codex)은 아래 페이지에 모아 뒀어요.

힉스필드 MCP 연결 방법

API 키는 필요 없어요. 힉스필드 계정 로그인으로 연결돼요.
MCP 주소: https://mcp.higgsfield.ai/mcp

① claude.ai / Claude 데스크톱 앱 (가장 쉬움 · 힉스필드 공식 안내)

  1. claude.ai(또는 데스크톱 앱) → 설정 → 커넥터(Connectors) → 커스텀 커넥터 추가
  2. 이름 Higgsfield, URL https://mcp.higgsfield.ai/mcp 붙여넣기
  3. 연결 → 힉스필드 로그인·승인 창에서 승인

Claude Code도 같은 claude.ai 계정으로 로그인돼 있으면 이 커넥터가 그대로 보여요(claude.ai Higgsfield).

② Claude Code에 직접 추가

bash
claude mcp add --transport http --scope user higgsfield https://mcp.higgsfield.ai/mcp

그다음 Claude Code 안에서 /mcp → higgsfield 선택 → 브라우저에서 힉스필드 로그인·승인.

③ 힉스필드 CLI 방식 (Node.js 필요)

힉스필드가 Claude Code용으로 안내하는 방식이에요. 이 방식만 Node.js(LTS)가 필요해요 — nodejs.org

bash
npm i -g @higgsfield/cli
higgsfield auth login
npx skills add higgsfield-ai/skills

연결 확인

Claude에게 "내 힉스필드 크레딧 잔액 알려줘" → 숫자가 나오면 성공이에요.

Codex에서 연결

bash
codex mcp add higgsfield --url https://mcp.higgsfield.ai/mcp
codex mcp login higgsfield

또는 ChatGPT 플러그인 디렉터리에서 Higgsfield 플러그인을 추가해도 돼요(ChatGPT·Codex 공용).

사용법

  1. 작업할 폴더에서 Claude Code를 열고 /selling-product-page 또는 "상세페이지 만들어줘"
  2. 셀링포인트 찾는 질문 10개에 답하기 (5~10분) — 상품·사진·자랑할 점·사는 사람·고민·구성·배송/교환·근거·올릴 곳·원하는 느낌
  3. 기획안 → 상세페이지 → 업로드 이미지가 자동으로 만들어져요
  4. 결과물
파일내용
1_기획안.md섹션별 문구·이미지 계획
2_상세페이지.html원본 (자사몰엔 이걸 그대로)
3_업로드이미지\스마트스토어, \쿠팡상세_전체.jpg 1장 + 조각_01.jpg… (순서대로 올리기)
4_올리는법.md플랫폼별 올리는 순서
5_배너\인스타 피드·썸네일

고칠 땐 "3번 섹션 문구 바꿔줘"처럼 말하면 그 부분만 고치고 이미지까지 다시 뽑아 줘요.

Codex에서 쓰기

Codex도 같은 스킬 형식(SKILL.md)을 읽어요.

  1. 두 폴더를 Codex 스킬 폴더에 넣어요.
    • Windows: C:\Users\(내이름)\.agents\skills\
    • Mac: ~/.agents/skills/
    • 특정 프로젝트에서만 쓰려면 그 프로젝트 폴더 안 .agents\skills\
    • 깃허브로 받을 땐 위 "방법 B" 복사 명령에서 .claude\skills를 .agents\skills로 바꾸면 돼요.
  2. Codex를 다시 켜고 /skills로 목록 확인 → $selling-product-page 또는 "상세페이지 만들어줘"
  3. 힉스필드 연결 → 위 "힉스필드 MCP 연결 방법" 페이지의 Codex에서 연결. 힉스필드가 없으면 GPT 이미지로 만들면 돼요.
스킬 문서는 Claude 기준으로 쓰여 있어요. Codex에서도 같은 역할의 도구를 찾아 쓰고, Python 스크립트(이미지 뽑기·쇼핑몰 변환)는 그대로 돌아가요. 가장 안정적인 건 Claude Code예요.

자주 막히는 것

  • /selling-product-page가 안 보여요 → 폴더가 한 겹 더 들어갔는지 확인 (skills\selling-product-page\selling-product-page\… ❌). Claude Code를 다시 켜기.
  • "python을 찾을 수 없어요" → Python 설치 때 PATH 체크를 안 한 경우예요. 다시 설치하면서 체크하거나 Claude에게 확인을 부탁하세요.
  • 이미지 뽑기가 안 돼요 → pip install playwright pillow 했는지 확인. Mac은 Chrome이 없으면 python3 -m playwright install chromium.
  • 힉스필드가 안 보여요 → 커넥터 연결 후 Claude Code를 다시 켜고 /mcp에서 상태 확인. 구독이 있어야 해요.
  • 금지 표현 → 식품·화장품·건강식품 광고 금지 표현은 스킬이 걸러 주지만, 최종 확인은 본인 책임이에요.
